You are working on the existing Blueprint-X repository.

DO NOT rebuild the project from scratch.

DO NOT replace the existing blueprint-processing pipeline.

DO NOT remove existing functionality.

DO NOT assume that the existing 103 tests passing means the geometry is accurate.

The current system is a desktop PySide6 application that accepts a 2D architectural floor-plan / blueprint image, processes it through a 10-stage computer-vision / AI / topology pipeline, generates structured architectural JSON v2.0, procedurally generates a 3D building mesh, previews that mesh inside the desktop application, and exports OBJ/MTL and GLB.

The current implementation is useful and works reasonably well on simple floor plans, but the 3D output and blueprint interpretation still need engineering improvements.

The next milestone is:

============================================================
MILESTONE 5
BLUEPRINT-X INTERACTIVE 3D / UNITY ENGINE
============================================================

PRIMARY OBJECTIVE:

Turn the existing Blueprint-X output into a high-quality interactive 3D architectural walkthrough.

The user should be able to:

1. Upload a blueprint in the existing desktop application.
2. Run the existing Blueprint-X analysis pipeline.
3. Inspect the detected walls, rooms, doors, windows, semantics and topology.
4. Generate a structurally correct 3D building.
5. Export the building and its metadata.
6. Open/import that generated building into Unity.
7. Enter a first-person view.
8. Walk through the generated building using WASD + mouse.
9. Collide correctly with walls.
10. Walk through valid door openings.
11. Interact with doors/windows/rooms.
12. Display room information and AI insights.
13. Visualize emergency/evacuation routes.
14. Eventually support disaster-management simulation.

The Unity environment must NOT become a separate unrelated application.

It must be directly driven by the architectural data generated by Blueprint-X.

PART 3 — FIX COORDINATE SYSTEMS BEFORE UNITY
============================================================

This is critical.

The current pipeline begins in image coordinates.

Image:

X → right
Y → down

Unity:

X → right
Y → up
Z → forward

The architecture must explicitly define the conversion.

Use a deterministic conversion such as:

image X → Unity X
image Y → Unity Z
height → Unity Y

Do not rely on arbitrary rotations after import.

The resulting building must have:

Y = vertical

X/Z = floor plane

The building origin must be predictable.

Prefer:

minimum floor-plan X/Y = origin

or another documented deterministic origin.

The same transformation must be used for:

- walls
- rooms
- doors
- windows
- furniture
- topology nodes
- player spawn
- navigation
- evacuation routes

Add tests for coordinate conversion.

============================================================

The current wall generator creates wall quads and openings.

Make the wall generation robust.

Do NOT simply create a rectangular wall and place a door texture over it.

Doors must create actual walkable openings.

START =========================== END

- openings

No accidental zero-area triangles.

No duplicate geometry where avoidable.

No z-fighting.

============================================================
PART 5 — WALL INTERSECTION HANDLING
============================================================

Architectural walls frequently intersect.

Do not blindly extrude every 2D line independently.

This can create:

- overlaps
- gaps
- spikes
- floating wall fragments
- impossible corners

Use the existing topology/geometry engine.

Where possible, construct walls from canonical segments and resolve intersections before 3D extrusion.

At minimum correctly handle:

- T-junctions
- L-junctions
- cross intersections
- collinear walls
- overlapping wall segments
- snapped endpoints

Do not break existing topology behavior.

Add regression tests.

PART 6 — FLOOR GENERATION

Each valid room polygon should be capable of generating a floor surface.

- avoid degenerate triangles

============================================================
