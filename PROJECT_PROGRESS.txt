1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Blueprint-X is a modular desktop application designed to convert 2D architectural 
floor plan images (blueprints, CAD drawings, rendered floor plans) into fully 
structured 3D building models, topological room adjacency graphs, and rich 
semantic metadata.

The system features an integrated 10-stage processing pipeline that combines 
classical Computer Vision (CV), Deep Learning (YOLO11 AI), Optical Character 
Recognition (EasyOCR), Planar Topology Graph Construction (DCEL), Procedural 
Interior Decorating & Window Synthesis, and 3D Mesh Generation with real-time 
OpenGL hardware-accelerated viewport rendering.

3. DETAILED 10-STAGE PROCESSING PIPELINE
--------------------------------------------------------------------------------
Stage 1: Preprocessing & Style Auto-Detection
  - Automatically identifies blueprint style: "simple" (clean line drawings) vs
    "rendered" (colored or textured architectural presentations).
  - Applies Grayscale -> Deskew -> CLAHE -> Dual Thresholding pipeline to isolate
    the structural wall mask while suppressing noise and text background.

Stage 2: AI Object Detection (Ultralytics YOLO11)
  - Detects architectural elements: doors, windows, furniture, stairs, columns.
  - Seamless fallback to CV heuristic detection if neural model weights are absent.

Stage 3: OCR Text & Scale Extraction (EasyOCR)
  - Extracts textual room labels (e.g., "Living Room", "Master Bedroom", "Kitchen").
  - Identifies scale notation (e.g., "1:100") to set real-world metrics.

Stage 4: Vector Wall Detection (OpenCV)
  - Skeletonizes structural mask -> Hough Line Transform -> Merges collinear line
    segments -> Snaps endpoints -> Detects door gaps -> Estimates wall thickness.

Stage 5: Geometry Graph Construction
  - Converts detected wall segments into a Double-Connected Edge List (DCEL) compatible
    planar graph with vertex snapping and edge intersection resolution.

Stage 6: Topology Engine
  - Performs leftmost-turn face traversal to extract planar room faces.
  - Isolates the exterior boundary face and builds an architectural room-adjacency
    graph (NetworkX).

Stage 7: Room Segmentation & Classification
  - Constructs clean room polygons from topological faces.
  - Calculates pixel/metric room floor areas and centroids.
  - Classifies walls into exterior outer walls (cyan) and interior partition walls (blue).

Stage 8: Semantic Fusion & Window Synthesis
  - Matches OCR text boxes to room polygons via point-in-polygon tests.
  - Synthesizes exterior wall windows for rooms adjacent to the outer boundary.

Stage 9: Procedural Furniture & Decorator Engine
  - Combines AI bounding boxes with classical contour heuristic detectors.
  - Procedurally populates rooms with 3D furniture models based on room semantics.

Stage 10: 3D Model Building
  - Extrudes 2D room boundaries and wall vectors into 3D geometry.
  - Computes wall vertices, normals, and face indices with precise door/window cutouts.
  - Generates floor/ceiling slabs and constructs 3D mesh representations.

5. EXPORT & INTEROPERABILITY FORMATS
--------------------------------------------------------------------------------
1. JSON Architectural Schema (v2.0.0):
   - Full structural export including wall vectors, room polygons, adjacency graph,
     door/window placements, furniture positions, and 3D bounding metadata.

2. Wavefront OBJ + MTL:
   - Industry-standard 3D mesh format (`building_3d.obj`) with separate material
     definitions (`building_3d.mtl`) for walls, floors, ceilings, doors, and windows.

3. Binary glTF (GLB):
   - Compact 3D binary format (`building_3d.glb`) ready for instant import into
     Unity, Unreal Engine, Blender, or web-based 3D viewers (Three.js / Babylon.js).
